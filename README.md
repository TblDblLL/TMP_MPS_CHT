# Генератор промокодов — внешняя обработка 1С

Исходник модуля управляемой формы: `Promokody_Form.bsl`. Рассчитан на платформу 1С:Предприятие 8.3 и управляемое приложение.

## Сборка `.epf` в Конфигураторе

1. **Файл → Новый → Внешняя обработка**. Имя объекта: `ГенераторПромокодов`, синоним: `Генератор промокодов`.
2. Создайте управляемую форму `Форма` и назначьте её основной формой обработки.
3. Создайте реквизиты формы из таблицы ниже. Для `Промокоды` добавьте в типе `ТаблицаЗначений` колонку `Промокод` типа `Строка(20)`.
4. Разместите реквизиты на форме в приведённом порядке. Для `РезультатПроверки`, `Маска` и `Вероятность` включите «Только просмотр». Для `Промокоды` выведите таблицу с колонкой `Промокод`.
5. Создайте команды `ВыбратьВсе` (заголовок «Выбрать всё») и `Сгенерировать` (заголовок «Сгенерировать»). Добавьте кнопки этих команд на форму.
6. Замените содержимое модуля формы кодом из `Promokody_Form.bsl` и назначьте обработчики событий из таблицы ниже. Сохраните обработку как `ГенераторПромокодов.epf`.

| Реквизит формы | Тип | Вид элемента / подпись |
|---|---|---|
| `Наименование` | Строка(100) | Поле ввода «Название» |
| `Алфавит` | Строка(36) | Поле ввода «Алфавит» |
| `СМаркером` | Булево | Флажок «С маркером» |
| `Маркер` | Строка(19) | Поле ввода «Маркер» |
| `ПозицияМаркера` | Число(2,0) | Поле ввода «Позиция маркера» |
| `ДлинаПромокода` | Число(2,0) | Поле ввода «Длина промокода» |
| `МаксимальноеКоличество` | Число(6,0) | Поле ввода «Максимально допустимое количество» |
| `КоличествоКСозданию` | Число(6,0) | Поле ввода «Количество к созданию» |
| `РезультатПроверки` | Строка(200) | Только просмотр, «Результат» |
| `Маска` | Строка(20) | Только просмотр, «Итоговый формат кода» |
| `Вероятность` | Строка(120) | Только просмотр, «Вероятность угадать» |
| `Промокоды` | ТаблицаЗначений | Таблица «Созданные промокоды» |

| Событие | Обработчик |
|---|---|
| Формы `ПриСозданииНаСервере` | `ПриСозданииНаСервере` |
| Формы `ПриОткрытии` | `ПриОткрытии` |
| `ПриИзменении` у всех восьми входных реквизитов | `ПараметрПриИзменении` |
| Команды `ВыбратьВсе`, действие | `ВыбратьВсе` |
| Команды `Сгенерировать`, действие | `Сгенерировать` |

Входные реквизиты для события `ПриИзменении`: `Наименование`, `Алфавит`, `СМаркером`, `Маркер`, `ПозицияМаркера`, `ДлинаПромокода`, `МаксимальноеКоличество`, `КоличествоКСозданию`.

## Правила

- Алфавит состоит из выбранных символов `0–9` и `A–Z`, без повторов. Кнопка «Выбрать всё» восстанавливает все 36 символов. Символы можно удалить из поля вручную.
- Длина — полная длина строки, включая маркер. Позиция маркера считается с **1**. Маркер постоянен для всего набора. Он может содержать символы полного алфавита, даже если они исключены из случайного алфавита.
- Число различных кодов равно `|алфавит|^(длина − длина маркера)`. Максимально допустимое количество не может превышать это число.
- Вероятность в форме рассчитана для **максимального допустимого количества** выданных кодов: `максимум / число различных кодов`. Строка `1 / N` — округлённая иллюстрация той же вероятности; дробь перед ней точная.
- Генерация создаёт указанное «Количество к созданию» уникальных кодов в таблице. Повторный запуск очищает таблицу и создаёт новый набор. Защита от совпадений с ранее выданными партиями не предусмотрена: для этого нужно хранить выданные коды в базе и проверять их при выпуске.
- Допустимая длина: 1–20 символов. Предел партии: 100 000 кодов. Эти ограничения удерживают расчёт в точности типа `Число` и не перегружают управляемую форму.

## Проверка по примеру

При алфавите из 34 символов, маркере `AA`, позиции 2, длине 11 и максимуме 20 000 маска равна `*AA********`. Число вариантов: `34^9 = 60 716 992 766 464`; вероятность одного попадания в выпущенный набор: `20 000 / 60 716 992 766 464`, или примерно `1 / 3 035 849 638`.

Генератор 1С `ГенераторСлучайныхЧисел` подходит для обычных акций, но платформа не заявляет его как криптографически стойкий источник случайности. Для кодов с существенной денежной стоимостью следует заменить источник случайности на криптографический и хранить выпущенные коды в базе.

Файл `.epf` нужно сохранить через Конфигуратор: в текущей среде платформа 1С не установлена, поэтому собрать и выполнить обработку здесь нельзя.
